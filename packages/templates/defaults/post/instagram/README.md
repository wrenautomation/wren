# Instagram footers

- `reel-footer`: under every Reel's caption (a Short's or a vertical's), after the title and
  description, with a blank line between. Caption links can't be clicked, so it sends people to
  the link in the profile.

No slots. Edit with `wren templates get post:instagram/reel-footer` and `set`, or in Library,
Templates. Making a version live waits in To approve.
