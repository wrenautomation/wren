# Start a subject

```sh
./bin/wren variants new <slug> --name "…" --kind text|image|video|page --type <content type> [--brief "his direction"] [--seed <study|sop|sample|file>]...
```

- **A brief** is his direction. Stay near it. Batch 1 spreads within it.
- **No brief** starts from scratch. Read each seed (a Weaver study's claims, the SOP, the skill). Spread wide: batch 1 samples share as little as you can.
- Add each tip from a seed as a guide, state `testing`: `guide add "…" --subject <slug> --source study --ref <study slug>`. Tag the samples that apply it (`references/guides.md`).
- Slug: short and plain (`opener-recruiters`). Name: what he calls it.
- Batch 1 samples have no parents. Each is a seed in the tree.
