# Sound kit licence

Every file in this folder is CC0 1.0 (public domain): https://creativecommons.org/publicdomain/zero/1.0/

- `click-*`, `key-*`, `pop-*`, `ding-*`, `error-*`, `glitch-*`, `hit-*`: from Kenney's Interface Sounds 1.0, UI Audio and Impact Sounds packs (www.kenney.nl), trimmed and leveled. Kenney asks for credit but does not need it.
- `swish-*`, `whoosh-*`, `riser-*`, `boom-*`: made with ffmpeg by `build.sh`, released here as CC0.

A file under any other licence never goes in this folder (the repo is public). It goes in the media bucket under `sfx/`, with its licence beside it, and `kit.json` names it with `"where": "bucket"`.
