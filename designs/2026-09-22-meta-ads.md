# Meta ads from the keyboard

2026-09-22. MVP item 1: run Meta ads without opening Ads Manager. `wren ads` → the `Ads`
Restate service → autobrowse's `meta` site (Graph v23, the token from the one Meta app).

## Shape

- `packages/channel-meta/src/ads.ts` — `metaAds(sites, {adAccountId?, pageId?, host?})`:
  `accounts`, `campaigns`, `launch(spec)`, `start(tree, dailyBudgetUsd)`, `stop(campaignId)`,
  `insights({preset, level})`, `setStatus`. Pure over `SiteClient`; tested against a
  recording fake.
- `packages/channel-meta/src/restate.ts` — `makeAds({sitesFor, adAccountId, pageId, host})`
  = service `Ads`. Always bound by the worker. Every Graph call is one `sites.call`
  invocation on the same Restate: a launch that dies after the ad set resumes there.
- `apps/cli/src/ads.ts` — `wren ads accounts|campaigns|launch|start|stop|insights`.

## Decisions

1. **Launch never spends.** `launch` makes campaign, ad set, creative, ad all PAUSED (the
   CLI forces it even if the file says ACTIVE). `start` is the one verb that turns money
   on and must say the daily budget; the service refuses `dailyBudgetUsd ≤ 0` as a
   terminal 400.
2. **Three ACTIVE writes, three gate asks.** Meta delivers only when campaign, ad set
   and ad are all ACTIVE. `start` sets the ad set first (budget = the amount the box's
   spend gate shows), then the campaign, then the ad (no amount → the gate asks the
   person). `stop` pauses the campaign only: that stops everything under it.
3. **Ad-set budget, not CBO.** The budget lives on the ad set (`daily_budget`, minor
   units). One ad set per launch keeps the ladder small; more ad sets = another launch.
4. **Spec from a JSON file.** Targeting is countries + age + interests (`flexible_spec`);
   creative is `link_data` (image by `image_hash`) or `video_data` (`advideos` by
   `file_url`). Local media goes through `WREN_MEDIA_BUCKET` like content does.
5. **Account and Page resolved once per client**: `WREN_META_AD_ACCOUNT_ID` /
   `WREN_META_PAGE_ID`, else the first of `/me/adaccounts` and `/me/accounts`.
6. **`ad_launches` is the ledger** (2026-09-22, replaces "no table yet"). The `Ads`
   service writes one row per launch (spec, the four ids, budget) and updates it on
   start/stop (`startedAt`, `stoppedAt`, `stopReason`). It is what `AdsWatch` reads and
   what `wren ads launches` prints; Meta stays the truth for spend and results.
7. **The guard only stops.** `AdsWatch/default` (daily) reads adset-level `last_7d`
   insights and calls `Ads.stop` on an active launch whose spend reached
   `WREN_ADS_PAUSE_AFTER_USD` (default $50) with zero clicks and zero results. One
   click or one result keeps it on — a person reads the numbers. Every pass with
   active launches is one channel message (warning when something was paused).
   Feeding results back into content ideas is still open.
