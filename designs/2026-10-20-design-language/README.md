# Design language artifact (reference for every UI build)

Copy of private artifact https://claude.ai/artifact/SuhuZqr8NPMQMDdd5UKWuu, the source of truth for the portal look.

- `design-language.html`: the built page. Open it in a browser and screenshot a section to compare with your story shot.
- `design-language.src.html` + `metro-render.{js,css}`: the source. Search it for a part's class (`.rg` ring, `.ck .bx` checkbox, `.tb` table) to read its exact CSS.

Rules: every UI brief names the artifact section it builds. Before hand-off, put the story shot next to the artifact section and fix each difference. When the artifact changes, copy the new files here in the same commit as the doc change.
