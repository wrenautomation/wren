# Blog box

2026-10-13. William: "what we should do for the blog stuff (no substack for now)".

## Decision

Write gets a Blog post box. The post stays a Markdown file in the lander repo (designs/2026-10-11-newsletter.md), so nothing about the site, RSS or email changes.

1. **Save.** Draft or Publish commits `src/content/blog/<slug>.md` through GitHub's contents API. The token reaches the lander repo only (`WREN_LANDER_GITHUB_TOKEN`). The push to main deploys it in a few minutes. A repeat of the same text commits nothing, so a retried step is safe.
2. **Row.** `blog_posts` keeps each post: Write lists them, Plan counts `published_at` against the Blog posts goal, `emailed_at` says it went out.
3. **Email.** Once `/blog/<slug>.json` answers, "Who would get it" shows the count, then Email hands it to `Newsletter` (each address once). A test goes to our own domain only.
4. **Animated posts.** The lander takes `.mdx` too, with a few components for posts written by hand or by an agent. The box writes plain Markdown.
