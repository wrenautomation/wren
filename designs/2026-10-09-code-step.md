# Inline code step

2026-10-09. Gaps item 9, entry 3 (`2026-10-07-product-audit.md`: GHL Custom Code, Code by
Zapier, Make Code). The team writes a few lines of JavaScript on the canvas to reshape an event,
with no hosted URL.

## Today

A custom step (`Own.run`) is a registered step name or an https URL the spine POSTs each event
to. One-off glue (split a full name, pick a field, compute a date) needs a server somewhere.

## Shape

- **Logic node `logic.code`, "Code".** Settings: `code` (long text), `kind` (as every logic
  node). Ports: in `in`; out `out` and `skip`.
- **What the code sees:** `event` (`{subject, kind, data}`, a deep copy) and `now` (ISO string).
  It's a function body; it `return`s:
  - an object: its fields merge into `event.data`, and the event leaves by `out`;
  - `null`, `false` or nothing: the event leaves by `skip` unchanged.
  - Anything else, or a throw, fails the step like any step (capped tries, Executions shows the
    error line).
- **Sandbox:** QuickJS compiled to wasm (`quickjs-emscripten`), in the worker's process. No
  `fetch`, no timers, no `require`, no file system. Caps: 1 s of run time (interrupt handler),
  32 MB memory, code up to 10,000 characters, a result up to 64 KB of JSON. A fresh context per
  call, so nothing leaks between events or clients.
- **Pure.** It changes nothing outside the walk, so it joins `PURE_STEPS`: a dry test runs it
  for real and shows the result. No effects, so publishing asks no extra yes.
- **Reaching out** stays with Send webhook and the https custom step.

## Portal

- In the palette under Logic. Its settings panel is the monospace textarea logic nodes use, with
  a note on the sandbox's limits. The node tester runs it: dry tests run pure steps for real, so
  Test this node shows what leaves and by which port, or the error. No separate handler.
- The canvas says the first line of the code, or "Write the code".

## Checks

- `logicProblems`: empty code, over 10,000 characters, or a syntax error (parsed with `new Function`,
  never run; the error names the problem).
- Ask Claude may add a Code node (the "never add a custom step" rule stands: a Code node is a
  logic node). The prompt lists it with the return contract.

## Limits

- JavaScript only. GHL also offers Python; not until someone asks.
- Team only, as the editor is.
- No secrets in code: the repo-wide rule. Keys come later through settings if a client needs one.

## Shipped

- 2026-10-09: `logic.code` (logic.ts), `code-step.ts` (QuickJS single-file wasm, bundles with
  esbuild), in the spine's and dry tests' steps, `codeProblems` on save.
