# Dev loop: prod data on this Mac, layout checked as text

2026-10-21. Two tools for fast UI work. Bugs show on messy prod data, so iteration runs against it.

## `pnpm dev` (apps/portal)

```
cd apps/portal && pnpm dev                       # http://localhost:5173, prod reads, writes off
WREN_DEV_WRITES=1 pnpm dev                       # writes reach prod too
WREN_DEV_EMAIL=someone@… pnpm dev                # act as another operator
```

- Vite runs the app with hot reload. `@cloudflare/vite-plugin` runs the real Worker (`src/worker.ts`) inside it. No second process, no local database.
- The Worker reads prod through Restate (`https://restate.wrenautomation.com`). `scripts/secrets.mjs run /wren/prod/env` puts `RESTATE_AUTH_TOKEN` in the process env. No file holds it. Its output is masked.
- `src/dev.ts`: active only when `WREN_DEV=1` and the host is localhost. Prod's Worker never has `WREN_DEV`.
  - Viewer: the operator `WREN_DEV_EMAIL` (default the team operator). No sign-in.
  - Write guard, fail closed. It lets through: GET pages, a service's read routes, `/api/pulse`, the media grant, a write's status, the writes socket. It refuses all else with 403. Live note rooms, `/api/agent`, `/oauth/`, `/o/`, key staging and dictation are always off.
- `src/dev-banner.tsx`: a corner mark, "dev · prod data · writes off".
- localhost never reaches the prod Worker, so its free request cap is safe.

## `wren-look` (packages/ui/.storybook)

Layout problems as text. No screenshot unless asked.

```
cd apps/portal && pnpm look --all --messy        # every page story on the running Storybook (:61001)
pnpm look http://localhost:5173/inbox --map      # the dev server; --map prints the page as text
pnpm look <story-id> --shot                      # a picture of each page with problems
./scripts/gates.sh look                          # the gate: built Storybook, all pages, messy, 390 + 1280
```

- `look.ts` runs in the page. Rules: text over text (two parts on one layer), text past its box, text cut without "…", a pane that scrolls down and sideways, a page that scrolls sideways.
- Layers: fixed, sticky and raised (absolute with a z-index) parts are their own layer. The page passes under them on purpose.
- Marks for intended cases: `data-look-over` (an overlay on text, such as the Open chip) and `data-look-scroll` (a pane meant to scroll sideways, such as a wide table or the map).
- `--map` uses autobrowse's layout reader (`@wrenautomation/autobrowse/layout`): each line of text at its place.
- Messy data: the Storybook toolbar "Data: Messy", or `globals=data:messy`. `mocks/api.ts` `stretch` makes data strings long, with accents, CJK and emoji. The app's own words (labels, states, views) stay as they are.
- `gates.sh ui` runs `look` after the story tests. About 4 minutes for 368 pages.
- Local hosts only. It never loads prod.
