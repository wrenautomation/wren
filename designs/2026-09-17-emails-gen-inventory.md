## 3. Pipeline
1. **Source/import** — `ingestion/importer.py:run_import` via `ingestion/schema.py`, `ingestion/formats.py` + niche `LEAD_SOURCE_FORMATS` (`agency-directory-csv`, `clutch-pages`, `shopify-pages`, `sec-investment-advisers`, `sec-firm-feed`). Google Sheets path: `sheets/client.py` + `sheets/snapshot.py:snapshot_rows` (CSV receipt + sha256). People: `people/importer.py:run_people_import`.
2. **Discovery/verification** — `discovery/service.py:run_domain_discovery/run_domain_verification` (DoH + ownership gate); `verification/service.py:run_verification` (`verification/local.py` free checks via `doh.py`, then `verification/millionverifier.py` or `FakeVerifier`).
3. **Enrichment** — `fetching/fetcher.py:PoliteFetcher` → `enrichment/crawler.py:run_crawl` → `enrichment/render.py:run_render` (Playwright tier 2) → `enrichment/email_scan.py:run_scan` (deterministic, `SCAN_VERSION="v3"`) → `enrichment/extraction.py:run_extraction/apply_extractions` (LLM, `PROMPT_VERSION="v2"`) → `enrichment/email_pick/{graph,run}.py` (LangGraph, `PICK_VERSION="v3"`) → `enrichment/resolution.py:build_candidates/queue_candidates/run_resolution`. Cache key everywhere: (subject, kind, model, prompt_version) in `enrichment/store.py`.
4. **Templates** — `.email` files in `src/emailsgen/niches/<niche>/templates/<arm>/<name>.email`, parsed by `outreach/authoring.py:load_templates` into the block tree in `outreach/templates.py` (Text/Field/Variants/Group; `{key}`, `{key|fb}`, `[[a|b]]`, `((…))`, `##` comments). Arms = directories (`marketing/`, `build/`, `documents/`, `operations/`); cadences from `outreach/sequences.py:two_email_sequence/three_email_sequence`.
5. **Compose** — `outreach/compose.py:compose` (+ `facts.py:facts_for`, `readable.py`, `provenance.py`, `pickers.py`). Deterministic, no LLM: personalization is template variants over stored facts. LLM is used only for extraction, email pick, and reply disposition (`outreach/disposition/graph.py`, `DISPOSITION_VERSION="v1"`), via `llm/client.py:make_llm` (`fake`, `anthropic`, or keycycle providers groq/gemini/openrouter/cohere/mistral/cerebras); spend/usage in `llm/audit.py` + `runs.py` ledger + views `llm_calls`/`stage_costs`; optional Langfuse in `llm/langfuse_tracing.py`.
6. **Send** — `outreach/policy.py:SendPolicy` → `outreach/tick.py:send_tick` → `outreach/deliver.py:send_due/_send_one` over `outreach/transport.py` (`ConsoleTransport`) or `senders/gmail.py:GmailTransport` (service-account DWD, `users.messages.send`). Roster: `senders/roster.py:load_roster` reading `senders_config.toml` (`[signature].text/.html` with `{page}` slot, `[[senders]]` with `address`, `display_name`, `niches`, `except`, `suspended`).
7. **Tracking/replies** — `outreach/inbox.py:sync_inbox` + `outreach/inbound.py` classification; `outreach/health.py` kill switches; `outreach/opens.py:sync_opens` (Cloudflare Worker in `infra/pixel/`); `outreach/postmaster.py:sync_postmaster`; `outreach/reconcile.py`; `outreach/suppress.py`.
8. **Friday report** — `scripts/weekly-report.sh` shells out to `claude -p --model claude-opus-5`, which runs read-only `emailsgen` commands and writes markdown to `reports/YYYY-MM-DD-weekly.md` (headline rates with Wilson intervals from `stats.py`, by niche/arm, deliverability, replies, pool burn-down, week-over-week diff, Monday action). Log at `reports/.weekly-report.log`.

## 5. Concurrency / idempotency
- Row locks: `deliver.py` uses `SELECT … FOR UPDATE SKIP LOCKED` (lines 261, 607, 616) for the paced walk and per-sender counters.
- Savepoints: `compose.py:_enroll_company` (`begin_nested`, one company per failure), `inbox.py:_write_event` (first-insert-wins on `gmail_id`).
- Upserts: `template_versions` ON CONFLICT DO NOTHING; `open_events` / `open_syncs` / `postmaster_days` ON CONFLICT.
- Dedupe keys: `companies.domain|source_key`, `leads.email`, `documents(url,content_hash)`, enrichment 4-tuples, `messages(enrollment_id,step)`, `messages.open_token`, `thread_events.gmail_id`, `open_events.remote_id`, three partial unique enrollment indexes, `sender_pauses` active partial unique.
- Idempotent cursors: `inbox_syncs.cursor_ms` (1-day overlap), `open_syncs.cursor_id`.
- State machines enforced in `domain/state_transitions.py` (`LEAD_TRANSITIONS`, `MESSAGE_TRANSITIONS`, `ENROLLMENT_TRANSITIONS`, candidate). Vocabularies in `domain/enums.py`: LeadStatus (imported/verified/suppressed/undeliverable), MessageState (draft/approved/rejected/sending/sent/skipped/failed/unknown), EnrollmentState (active/finished/stopped), StopReason, EnrollmentKind, ThreadEventKind, BounceClass, ReplyDisposition, DispositionSource, ApprovalSource, PauseSource, RejectReason, SuppressionKind/Reason, CandidateEvidence/State, DocumentKind, EnrichmentKind, PersonOrigin, ImportErrorKind, VerificationResult. Each is mirrored as a DB CHECK via `models._enum_check`.
- Intent-before-act: Message-ID minted before transport, `APPROVED→SENDING` committed first; ambiguity → `UNKNOWN`, only `reconcile.py` resolves. `enrichment/shard.py:Shard` (`--shard i/n`) parallelizes long loops by `id % n`.
