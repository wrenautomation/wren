# Views: open and shut each part, focus, saved defaults (2026-11-06)

Task WA-1153. William, 11-06: "being able to close and open everything and zoom into subviews (blocking out everything else mentally, and having default views too for organizational purposes) is super important here".

## What is there today

| Place | Open/shut | Focus | Saved / default |
|---|---|---|---|
| Map, flat | each fold (`fold.open`), depth steps (MetroDepth) | NodePanel "open on its own" → FocusPage | saved views hold `parts=` only; listed in ⋯ Map tools; Home view on FocusPage |
| Map, Layers | Together/Apart: all plates at once | Open: plate → flat focus | none |
| Variants tree | none | path light on select; "Good line" filter | none |

Gaps: views are hidden in ⋯; a view keeps no look, floor or folds; Layers has no default and no per-plate shut; the tree has no branch focus or fold and forgets its mode.

## Target (cost zero)

1. One **Views** menu in every map bar: the view on screen by name, every saved view, Whole map, Save view, Make home.
2. A saved view keeps everything that decides what you see: the parts, the look, the floor, the split, the fold depth, the folds open or shut, the plates shut.
3. Home works for any view: "/" opens it, Flat or Layers.
4. Layers: each plate opens and shuts on its own.
5. Tree: focus a branch (the rest goes), fold a branch (its children go to a "+N" chip), and the tree comes back as you left it, per subject.
6. Later: the whole portal follows the view (F4 of `2026-10-23-focus-view.md`, still William's call).

## Decision: what a saved view holds

| Option | For | Against |
|---|---|---|
| **A. The map address as a query string in `saved_views.params`** (`parts`, `look`, `floor`, `split`, `shut`, `depth`, `open`, `close`) | No schema change; a view and a pasted link are one thing; old views (`parts=` only) still read; unknown keys are ignored | Fold ids live in text: a shape change can leave stale ids (they are ignored) |
| B. A typed JSON body in `params` (`{v:1, look, folds…}`) | A zod schema checks it | Two forms in one column; a view is no longer a link |
| C. A `map_views` table with columns | Checked by the database | A migration and a new API for state the browser owns; each new knob is a migration |
| D. All view state in the URL (fold state leaves local storage) | A saved view is literally a URL | Every fold click writes history; long URLs on a big map |

Ranked by: one seam (a view = an address), no new store, then robustness to shape change.

**Chose A.** Fold state stays in the browser (`kept.ts`) while you work. Opening a view writes its depth and folds into that store once, then drops them from the address, so a fold click never writes history. Saving reads the store back into the view.

## Build

**Views menu** (`apps/portal/web/src/map/views.tsx`). A `Views` button in the Map bar and on FocusPage, labelled with the view on screen ("Whole map" when none). The pop lists Whole map, then each view (its look, Home and Shared marks), then Save view (new, or update the one on screen) and Make home. The ⋯ list goes.

**Apply.** A view with parts opens FocusPage, as now. A view without parts opens "/" with `sv=<id>` and its `look`, `floor`, `split`, `shut`; its `depth`, `open`, `close` go to the kept store once. Home: a view without parts is applied on "/" unless the address names a look or `whole=1`.

**Layers, per plate.** `shut=<node:id,line:id…>` in the address. A shut plate lands on its stop as a card (its `--zn` is 0), the dashed drop goes. The plate's tag gets one button: Shut / Lift. Together and Apart still move every open plate.

**Tree.** `branch=<id>` draws only that sample's line (its parents up to the brief and all it grew). A bar over the tree names it, with Show all. `fold=<ids>`: a folded sample hides what grew only from it and shows "+N". Both are buttons in the sample's card. The mode (All samples / Good line), branch and folds are kept per subject in this browser and come back when the address names none.

## Not built, and why

- Layers of a set of parts (a view with parts and `look=layers`): Layers takes the whole level today. A view with parts opens flat.
- Named saved views of a tree: a subject is already the scope; the kept mode per subject is its default.
