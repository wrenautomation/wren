## 1. `Rows` (new `packages/ui/src/rows.tsx`)

One component, generic on the row type. Suggested props (change names if a better one fits, keep the parts):

- `label`: what the rows are, for aria ("people").
- `columns: RowsColumn<T>[]`. A column has `key`, `label`, `icon` (a kit icon name, for its header), `align` (start or end), `width` (px, optional), `cell(row, i)`, `phone` (shown on the phone, at most one column), `sort` (a header node, so `List` passes `SortHead`).
- `name`: the name column, always first after the gutter. It takes `title(row)`, `href(row)`, an `avatar(row)` (initials) or a `mark(row)` (a `Cue` state), and an optional `sub(row)` line (a preview or fold). It draws the "Open" chip on row hover, which goes to `href`.
- `lines`: the rows, or `ListLine` items (group, tier, box, row) as `useListTable` makes them. Virtual lines through `useLines` stay (`VIRTUAL_FROM`).
- `pick`: optional selection (`picked(id)`, `toggle(id)`, `all`, `toggleAll`).
- `act(row)`: optional row end. It gives `{ main, more, reply, page, busy, run }`, as `RowActions` takes now.
- `open`: optional `{ id, onOpen(row, i) }`. A row click calls it. A click on an input, link or button inside the row does not.
- `cursor`, `rowState(row)` (`going` word, `changed`), and `foot`.
- `group`: optional `{ folded, toggle(key) }` for folds.

### F1 look (exact to the artifact)

- Header row 34px, 12.5px `--ui-ink-3`, hairline top and bottom. Each header has its column's icon before the label (14px, `--ui-ink-3`).
- Column lines: a hairline between cells (`th + th`, `td + td`). Row lines: the existing `border-b border-(--ui-hair)`. Row min height stays `--layout-row` (about 42px). Hover is `--ui-hover`. Selected is the tint ground.
- Gutter checkbox: hidden (opacity 0) until the row is hovered or focused, or the box is checked. Once any row is checked, every gutter box shows. Keep it in the tab order and keep its label.
- Name cell: a 22px round avatar (tint ground, accent text, initials) or the mark, then the title (weight from `TITLE_WEIGHT`), then the Open chip (11.5px, opacity 0 until row hover or focus within).
- `Pill` (export it): a kind or queue pill, `color-mix(in srgb, var(--c) 15%, var(--ui-paper))` ground, `color-mix(in srgb, var(--c) 72%, var(--ui-ink))` text, radius `--ui-leaf-chip`.
- `StageSquare` (export it): an 8px square in the state's line colour before the label.
- `Age` (export it): a wait as words ("2 days"). Late is `color-mix(in srgb, var(--ui-warn) 80%, var(--ui-ink))` and weight 650. Text only, never a fill.
- Row end: one quiet 28px icon button (radius `--ui-leaf-button`) always shown: the reply, else `main[0]`. The rest of `main` and the ⋯ menu show on hover, focus or cursor, as now. The quiet icon turns accent on row hover. Change `RowActions` for this; do not copy it.
