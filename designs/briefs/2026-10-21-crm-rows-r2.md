## Target

A row click opens a peek, not the whole record. The peek is the existing `Panel` (the `?<one>=id` param, J and K, Esc, a `BottomSheet` on the phone). Do not build a second panel. Its body changes:

1. Head: the 32px avatar or mark, the title, an "Open" button to the full record (`place.page(id)`, what "Open as a page" does now), prev, next and close.
2. Properties: a `dl` with a 96px label column. The fields are the page's `peek.fields`, else the list's columns without the title. Cells draw with `FieldCell`, so a stage shows its `StageSquare`.
3. Last activity: the newest one to three items of the record's own activity or timeline, each with a small "who · channel · when" line on a wash ground (`.msg`). Use the read the record page uses now. No new endpoint.
4. The main action: the page's reply box when it has one (the same `reply.box` the row's reply uses: one write path). Else the row's first main action as a button, through the same `rowRun`. The Undo toast shows as on the row.
5. Under these, a quiet "Open the full record" link. The full `RecordBody` no longer draws in the panel.

The peek is the default for every list page. A page can set `peek: false` to keep today's full panel. Give `ListPage` `peek?: false | { fields?: string[] }` and wire it through `apps/portal/web/src/records.tsx`.

The panel floats at the right, 560px, as now. The artifact draws it beside a narrowed table; that is a choice for William, not built here.

## People

- `peek.fields`: stage, warmth, persona, last touch, last channel.
- Last activity: the newest items of the person's timeline (the same source as `profileExtras`).
- Reply: the person's reply box from `conversation.tsx` if it takes a person; else the first main action. Say which in the report.
- Name cell: initials avatar. Stage column: `StageSquare` (R1 set the line colours). Last touch column: `Age`.
- Phone row: name, stage, the quiet action.
- No owner: `people.profile` has no owner field. Leave it out. The planner lists it for William.
