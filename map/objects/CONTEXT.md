# objects/

One card per noun: a table, a type, a file kind, or a service set. Clusters are by how an editor asks, not by package. `_index.md` is generated by `../_meta/build.sh`; add a card by copying `../_templates/object.md`, then rebuild.

| Cluster | Nouns |
|---|---|
| `leads/` | company, person, lead, sighting, suppression |
| `ledger/` | run, import |
| `research/` | document, enrichment, discovery-attempt, contact-candidate, verification |
| `email/` | enrollment, message, thread-event, template, sequence, roster, send-policy, transport, sender-pause, open-event, inbox-sync-cursor, postmaster-day, report |
| `content/` | idea, draft, content-metric, platform, media, playbook |
| `ads/` | ad-launch |
| `sms/` | sms-number, sms-contact, sms-message, sms-event, sms-provider |
| `platform/` | settings, niche, offer, loop-object, restate-services, db-schema, worker, cli, phone-worker, notifier, llm-client |

Not carded (read the file): the pure helpers `send/dates.ts`, `inbox/inbound.ts`, `send/lead-timezone.ts`; the research fetch stack `packages/research/src/fetch/`; `deploy/pixel`, `deploy/prober`, `apps/prober`.
